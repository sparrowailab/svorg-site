# Дизайн сайта Sparrow

Источник правды по бренду — брендбук `~/Downloads/Sparrow Brandbook.html` (13 разделов,
собран в pen.dev). Этот файл — его выжимка в той части, которая нужна при правке сайта,
плюс решения, принятые уже в вёрстке.

## 1. Пять вопросов (design-ui §1)

**Назначение.** Посетитель оценивает, можно ли доверить Сергею внедрение ИИ, и уходит
в Telegram или на один из продуктов. Чаще всего читают кейсы.

**Аудитория.** Собственники и руководители малого и среднего бизнеса в России. Приходят
с мобильного по ссылке из Telegram или с десктопа из поиска. Читают по диагонали,
ищут цифры и доказательства.

**Тон.** Спокойный инструмент, не витрина агентства. Каждое утверждение подтверждено
цифрой, кейсом или ссылкой на работающий продукт. Без восклицаний и обещаний.

**Одна запоминающаяся деталь.** Знак воробья с лаймовой механикой внутри: живое,
собранное как система. Лайм появляется редко и означает «здесь результат».

**Ограничения.** Статические HTML без сборки и зависимостей. Светлая тема одна,
тёмной нет. Шрифты с Google Fonts. Плотность данных высокая: в кейсах таблицы цифр.

## 2. Токены

| Роль | Значение | Где |
|---|---|---|
| Графит | `#0E0E10` | текст, тёмные полосы |
| Бумага | `#EDEFF2` | фон документа |
| Белый | `#FFFFFF` | карточки, поля |
| Лайм | `#C9F24E` | акцент, **не более 10% площади** |
| Лайм-текст | `#3C4A0A` | текст на лайме |
| Лайм-тинт | `#EAF6C8` | мягкая подложка |
| Серый текст | `#6B7280` / `--muted` | подписи |
| Линия | `#E3E6EA` | разделители |

Пропорция на макете — 60 бумага · 30 графит · 10 лайм.

**Убрано из палитры намеренно:** пастельные mint, peach, sky, salmon. Восемь равноправных
фонов размывали сигнал лайма. Смысловые различия передают вёрстка и подписи, а не цвет.
Не возвращать.

## 4. Знак и локап

- Файлы: `assets/sparrow-mark-dark.svg` (на светлом), `assets/sparrow-mark-light.svg` (на тёмном).
  Это обрезанные по краске версии; оригиналы из брендбука — `sparrow-logo-*.svg`, в вёрстке
  не используются: внутри половина пустого поля по горизонтали.
- Локап по пропорции брендбука: **размер слова равен высоте знака**, зазор около половины
  высоты. Сейчас 34 / 33 / 18 px в шапке, на мобильной 26 / 25 / 13.
- Свободное поле вокруг локапа — не меньше половины высоты знака.
- Минимальный размер знака на экране 24 px. Ниже механика сливается.
- Фон под знаком только `#0E0E10`, `#FFFFFF` или `#EDEFF2`.
- Фавиконка — графитовый квадрат с кольцом и лаймовой точкой, мотив «глаз — точка фокуса».
  На 16 px воробей нечитаем, поэтому знак туда не ставим.

## 5. Имя

Бренд — **Sparrow**. SVORG остаётся только юрлицом в строке копирайта. Основатель —
Сергей Воробьев, через «е» по всему сайту. В тайтлах суффикс «· Sparrow».

## 6. Принятые решения по вёрстке

- Классы знака называются `footer-mark`, `hero-mark`, `err-mark`. Прежние `*-whale`
  остались от старого логотипа, переименованы — не возвращать.
- Зоны нажатия вне предложений — не меньше 24 px по высоте (WCAG 2.5.8). В подвалах это
  достигается вертикальным `padding` ссылки, а не высотой строки; отступ списка уменьшен
  на ту же величину, чтобы визуальный ритм не менялся.
- Заголовки — `text-wrap: balance`, абзацы и подписи — `text-wrap: pretty`.
- Цифры счётчиков и метрик — `font-variant-numeric: tabular-nums`.
- Фокус с клавиатуры — кольцо `--lime-deep` 2 px с отступом 3 px. `outline: none` не ставить.
- `prefers-reduced-motion` глушит переходы и hover-сдвиги. Новые анимации добавлять
  только внутри этого правила.
- Шапка выровнена с контентом: `.nav-inner` имеет те же боковые поля `--pad`.
- Плотные скриншоты интерфейсов показываем целиком (`.shots-grid.full`, `object-fit: contain`)
  и даём открыть в полном размере по клику. `cover` режет смысл кадра.
- Число не разрывается. Внутри разрядов, перед знаком рубля и между числом и единицей —
  неразрывный пробел (`890&nbsp;000&nbsp;₽`, `14&nbsp;дней`); в «120/мес» дробь склеена
  `&#8288;`. На 320 px колонка таблицы ýже суммы, поэтому без этого «890 000 ₽» распадалось
  на три строки.
- Таблицы «До и после» на узких экранах: размер текста и отступ между колонками плавные
  (`clamp`), перенос по слогам (`hyphens: auto`) — только в первой колонке. Фиксированный
  размер либо разгонял таблицу шире экрана, либо рвал числа. Ширину колонок не задаём:
  таблица сама раздаёт её по содержимому.

## 7. Проверка

Любая правка UI считается готовой только после прохода агентом `ui-verifier`
на desktop и mobile ширине (§30.9B). Локальный просмотр — `./.deploy/deploy.sh`
выкладывает и проверяет домен, но это не заменяет проверку сценария.

## 8. Известные отклонения

Не исправлены, общие для всех двенадцати кейсов — чинить разом или не чинить:

- в кейсах `H3` идёт до первого `H2`;
- хлебная крошка дублирует надстрочник обложки;
- сетка из трёх карточек на десктопе даёт 2+1.
